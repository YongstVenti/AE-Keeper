# AE Keeper · 网页留痕

AE 系列中的网页保存工具。一个 Windows 桌面软件同时保存 Edge 与 Chrome 的窗口和标签页，按天归档，随时找回。

采用海松绿与浅薄荷白配色，沿用 AE 系列标识；应用内使用得意黑。Windows 11 支持圆角窗口与 Acrylic 标题栏。

当前版本：**0.5.2**。适用于 Windows，采用 MIT 许可证。

![AE Keeper 演示界面](docs/images/app-preview.png)

*截图使用演示数据，不包含真实浏览记录。*

## 功能

- 无需浏览器扩展，连接本机 Chrome、Edge 后读取所有可见窗口；默认排除无痕。
- 定时保存窗口快照，记录观察到的网页，合并检索两种浏览器的书签。
- 每天保留一份自动最新的完整双浏览器快照；支持额外保留多份、指定主存档和按原浏览器窗口恢复。
- 本地 SQLite 档案，JSON 导入导出。无需账户，不上传浏览内容。
- 桌面窗口：按任务栏窗口范围保存，默认包含最小化窗口；保存资源管理器多标签路径、可读取的终端进程目录与本地窗口预览，支持卡片浏览、手动保留和选择恢复。

## 高清画面与节省空间

在“保存设置”勾选“同时保存高清画面”，选择长边上限（1280/1920/2560/3840）、压缩方式和缩略图尺寸。默认关闭高清以节省空间。高清图与缩略图一起保留，双击卡片可选择“原始比例 100%”滚动查看文字，或适应窗口。

手动采集按系统提供的源画面尺寸投影，必要时分块拼接，不把小图放大。旧缩略图不能补成历史高清画面；受保护或不可读的窗口只保留可用旧图及实际截图时间。

![高清保存设置（合成演示）](docs/images/hd-settings-preview.png)

采用内容寻址的 SQLite 二进制对象，重复图片和相同浏览器快照只保存一份；快照元数据使用 Zstandard 无损压缩。日期、备注及浏览记录的标题和网址保留可检索结构。第一次升级会在数据目录保存已校验的旧数据库副本，再事务化转换档案。导出的 JSON 继续兼容旧备份格式，包含完整图片，因此会比内部档案大。详情与实测见 [存储方案](docs/storage.md)。旧软件不能直接读取新版压缩数据库；回退需恢复升级前的数据库副本。

## 运行

需要 Windows 10/11、Python 3.13 及支持现有实例连接接口的 Chrome/Edge。本版本主要在 Windows 11 和两种浏览器 154 版本验证。

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python app.py
```

## 连接浏览器

1. 启动软件，点击“连接两个浏览器”，也可以在 Edge 或 Chrome 栏中单独点击“连接”。
2. 在对应浏览器的设置页开启“Allow remote debugging for this browser instance”（允许对此浏览器实例进行远程调试）：Chrome 为 `chrome://inspect/#remote-debugging`，Edge 为 `edge://inspect/#remote-debugging`。
3. 浏览器弹出连接请求时点击“允许”，回到软件确认两个浏览器均显示“已连接”，再展开各窗口检查标签页。

软件不会代替用户授权；拒绝或超时后不会反复请求。重启后需要重新连接。如果设置页没有对应开关，当前浏览器版本或组织策略可能不支持这种连接方式。

默认每 60 秒保存一次，可在“保存设置”中调整。浏览记录保存的是软件运行并成功读取期间观察到的网页；两次采样之间打开后又关闭的页面可能没有被记录。

## 每日存档

前三栏依次为“浏览器标签页”“桌面窗口”“每日存档”。每日存档分为“浏览器页面”和“桌面窗口”，切换后分别查看两种数据。桌面每日存档每天显示保存时间最晚的一份，自动更新及“保存当前桌面”会更新当天自动记录；同一秒保存时选择最后写入的快照。已有手动历史快照仍可在第二栏查看，不因导航改版删除。筛选只作用于每天最后一份，不会用较早快照冒充最后记录。

![每日桌面存档（合成演示）](docs/images/daily-desktop-preview.png)

每天自动更新一份最新的完整 Edge + Chrome 快照。在“窗口快照”中选中历史快照，可以把它加入指定日期的每日文件夹，选择替换主存档或额外保留。

只有一份时直接显示；有多份时展开日期，查看其他快照并设置主存档。手动指定的主存档不会被后续自动保存覆盖。恢复时按浏览器和窗口打开可用的网页网址；登录状态、标签组和固定标签页不保证还原。

### 更改归档日期

在每日存档的“浏览器页面”或“桌面窗口”中选中一份，点击“更改日期”，输入 YYYY-MM-DD，例如凌晨补存后改到昨天。只修改归档日期，实际保存时间和内容保留；浏览器主存档被移走时，原日期的其他快照继续保留。移入已有日期的浏览器快照设为主存档，原快照成为子项；桌面每日列表继续按实际保存时间选最晚的一份。移动后的记录转为手动保留，后续自动保存不会就地覆盖；导出、导入同样保留自定日期。

## 数据与兼容性

### 桌面窗口

“桌面窗口”默认按同一保存间隔自动更新当天的一份非空存档，也支持“拍摄并保留全部窗口”留下额外的独立记录。默认包含最小化到任务栏的窗口，可关闭此选项；隐藏到托盘、工具弹窗、AE Keeper 自身和其他虚拟桌面的不可见窗口不在采集范围。被其他窗口遮住的普通窗口会保存。没有窗口时保留已有当天存档。

默认同时保存本地 WebP 窗口缩略图。定时保存尝试读取窗口画面，无法绘制的最小化窗口沿用同一窗口上次可读的预览，并标出截图时间；没有历史图时显示占位，窗口信息仍然保存。手动拍摄会短暂显示本软件的临时预览板，通过系统 DWM 缓存拍摄包括最小化窗口在内的画面，不展开、导航或切换原窗口。截图可能受应用绘制方式、系统保护或遮挡影响；不可读的画面不会伪装成有效截图。渲染在独立进程中运行，超时保留已完成图片和窗口信息。

存档默认以窗口卡片显示，双击画面可查看保存的图，也能切换到“详细清单”展开文件夹和终端目录。旧存档没有截图时不会补造历史画面。

同一天重新启动 AE Keeper 时，先把上次的自动快照保留为“上次运行保留”，再更新当前现场，避免启动后的空工作环境覆盖重启前的进度。软件运行时才会自动采集；可在“保存设置”开启安装版开机启动，也可用 `--workspaces` 直接打开此栏目。`--capture-workspace` 会手动拍摄一份新现场并打开预览。普通开机启动和定时保存不会弹出预览板。恢复始终由用户选择后发起，不会在开机时自动执行命令或打开所有软件。

资源管理器通过 Shell COM 读取同一窗口的文件夹标签页。恢复会创建新窗口，再为它添加标签页，不导航或关闭已有窗口。Windows 10 等不支持标签页的系统会退回独立窗口；不存在的路径跳过，标签顺序与选中项不保证一致。

Windows Terminal 在能把宿主对应到一个窗口时读取 shell 子进程的目录；宿主有多个窗口且无法可靠对应时只保留软件入口，不推测会话归属。恢复为新的 shell 标签页，分屏会展开成标签页。**进程目录可能与 PowerShell 等 shell 的逻辑 `pwd` 不同**；不能接续命令、进程、终端滚动内容、环境变量或 WSL 会话。不会采集或重放 shell 命令行。

其他软件保存标题、入口和窗口位置，恢复前可自行勾选；不保证恢复项目、文档或未保存内容。浏览器网页继续使用“每日存档”恢复。窗口布局在能可靠识别新窗口时尽量还原；显示器变化后会限制在当前桌面可见范围。

桌面窗口与图片合计单独预留默认 20 MB（可在保存设置调至 5—2000 MB），与浏览器共享保留天数。自动保存、包含最小化窗口和保存预览图的开关位于“桌面窗口”栏目。导出完整备份包含窗口、本地路径和截图；截图可能包含网页、聊天、终端输出或其他可见私人内容，请自行确认可公开的内容。旧备份没有桌面窗口字段或图片也可以导入。

参考：[微软 ShellWindows 文档](https://learn.microsoft.com/en-us/windows/win32/shell/shellwindows)、[Windows Terminal 启动参数](https://learn.microsoft.com/en-us/windows/terminal/command-line-arguments)。

### 浏览器档案

浏览器连接只采集标签标题、网址和窗口信息，不读取 Cookie 数据库、登录凭据或页面正文。桌面窗口的预览图另外保存可见窗口画面，因此可能包含网页、聊天或终端输出；可关闭预览图保存。标题、网址与图片可能包含个人信息，请谨慎分享导出的档案。恢复网址需要网络和原网站登录状态；不能把未读取到的网址或未运行期间的变化补回来。

旧版“浏览留痕”的档案、安装目录和备份格式继续兼容。名称更新不会迁移或清空原数据。默认档案路径：`%LOCALAPPDATA%\BrowseTraceDesktop\data\archive.sqlite3`。

## 验证与打包

```powershell
python -m unittest discover -s tests
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --onefile --windowed --name AEKeeper --icon assets/ae-keeper.ico --version-file version_info.txt --add-data "assets;assets" --hidden-import win32com.client app.py
```

生成的程序可直接运行。以 `--install` 启动安装界面，或把安装副本命名为 `AE Keeper-安装.exe`。安装到当前用户目录并生成 AE Keeper 桌面快捷方式。

演示模式使用本地示例网址，不连接实际浏览器：

```powershell
python app.py --demo --data-dir ./demo-data
```
